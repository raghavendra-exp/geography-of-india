## 🧭 Overview

**BHARAT ATLAS MASTER** is a comprehensive, pedagogical, offline-first web application designed to transform Indian Geography preparation from fragmented rote memorization into an integrated **causal-scientific learning experience**.

Built with modern React 18, Vite 6, and Tailwind CSS, it features dual cartographic aesthetic themes (**Parchment Atlas** and **Night Atlas**), georeferenced vector SVG interactive maps, atmospheric physics simulators, a hydrological drainage basin analyzer, and **500 verified bilingual MCQs** with 3-level progressive hints, official UPSC trap alerts, and confidence tracking.

---

## 🌟 Core Pedagogical Modules

### 1. 🔄 Master Causal Flow (16 Interconnected Stations)
Geography is taught as an unbroken causal chain:
$$\text{Geology} \longrightarrow \text{Relief} \longrightarrow \text{Drainage \& Climate} \longrightarrow \text{Soils} \longrightarrow \text{Vegetation} \longrightarrow \text{Crops \& Human Settlement}$$
* Explores 16 stations from Location & Frontiers to Geology, Himalayas, Northern Plains, Peninsular Plateau, Coastal Plains, Drainage, Climate, Soils, Vegetation, Agriculture, Minerals, Industry, Disasters, and UPSC Traps.
* Features "Why It Matters (Causal Pivot)", downstream dependency links, high-yield Prelims facts, and direct station practice triggers.

### 2. 🗺️ Interactive Vector Map Lab & Blind Pointing Drill
* **Georeferenced SVG Atlas:** Mapped precisely to India's bounding coordinates ($6.5^\circ\text{N} - 37.5^\circ\text{N}$, $68.0^\circ\text{E} - 97.5^\circ\text{E}$).
* **6 Toggleable Thematic Layers:** Mountain Passes ($36$ high-altitude passes), Peaks ($14$ summit peaks), River Paths ($9$ primary systems), Physiographic Divisions ($6$ macro divisions), Biosphere Reserves (all $18$ national reserves with $12$ UNESCO MAB sites), and Mineral Belts.
* **Inspect Drawer:** Deep-dive into elevation, range, state, strategic connectivity, and highway routes (e.g. NH-1 via Zoji La, NH-44 via Banihal).
* **Blind Map Pointing Drill:** Interactive game with **Learn**, **Practice**, and **Test** modes to calibrate spatial recognition under exam conditions.

### 3. 🌪️ Simulators & Topographic Cross-Sections
* **8-Stage Monsoon Physics Simulator:** Step-by-step atmospheric mechanics:
  1. Intense Summer Continental Heating (Thar/Multan thermal low $<996\text{ hPa}$)
  2. ITCZ Migration to $20^\circ-25^\circ\text{N}$ & Mascarene High pressure gradient reversal
  3. Somali Low-Level Jet (Findlater Jet) moisture advection
  4. Onset / "Monsoon Burst" over Kerala with Tropical Easterly Jet (TEJ) divergence
  5. Bifurcation into Arabian Sea & Bay of Bengal branches
  6. Orographic funneling in Meghalaya & Aravali parallelism
  7. Active-Break cycles, Madden-Julian Oscillation (MJO), and monsoon depressions
  8. Retreating Monsoon & Northeast Monsoon precipitation over Coromandel Coast
* **Topographic Cross-Section Profiles:**
  * *Profile 1:* Shiwalik $\rightarrow$ Bhabar (streams disappear underground) $\rightarrow$ Terai (marshy swamps, streams re-emerge) $\rightarrow$ Bhangar (older alluvium, kankar) $\rightarrow$ Khadar (younger floodplains).
  * *Profile 2:* Western vs Eastern Ghats asymmetry, orographic cloud blocks, and rain-shadow semi-arid interiors.
* **Agro-Climatic Matching Challenge:** Interactive mini-game matching commercial crops (Cotton, Jute, Tea, Coffee, Wheat, Sugarcane) with ideal soil types, rainfall requirements, and leading producing states.

### 4. 🌊 Hydrological Drainage Basin Explorer
* Complete anatomical breakdown of **14 major river systems** (Ganga, Indus, Brahmaputra, Godavari, Krishna, Cauvery, Narmada, Tapi, Mahanadi, etc.).
* **Left-Bank vs Right-Bank Tributaries:** Structured strictly according to downstream flow direction (crucial for UPSC Prelims elimination).
* Source-to-mouth flow chains, major multi-purpose dams/barrages, and active inter-state river water disputes (Cauvery, Krishna, Mahadayi, SYL Canal).

### 5. 🎯 500-Question Practice Arena
* **500 High-Yield MCQs:** Covering all 10 official modules with bilingual English & Hindi support.
* **Progressive 3-Level Scaffolding Hints:** Broad clue $\rightarrow$ Conceptual elimination $\rightarrow$ Direct mechanism.
* **Official UPSC Trap Warnings:** Highlights deceptive statements, direction reversals, and typical misinterpretations.
* **Confidence Rating:** Tag your confidence as *Guess (25%)*, *Unsure (50%)*, *Sure (75%)*, or *Very Sure (100%)* to calibrate intuition.
* **Personal Notes:** Add custom study notes to any question.

### 6. ⏱️ UPSC Prelims Exam Simulator
* **Presets:**
  * **100-Question UPSC GS-I Mock:** 120 minutes, 200 marks, strict $-0.66$ negative marking.
  * **50-Question Sectional Drill:** 60 minutes, 100 marks, $-0.66$ negative marking.
  * **30-Question Rapid Drill:** 35 minutes, 60 marks, speed and accuracy training.
* **TCS iON Examination Interface:** Standard Question Palette (Answered, Unanswered, Marked for Review, Answered & Marked for Review).
* **Comprehensive Scorecard:** Net score, accuracy percentage, time allocation, and syllabus performance matrix.

### 7. 🗂️ Flashcard Deck (Leitner 5-Box System)
* Spaced repetition cards for high-frequency factual targets (Panch Prayags, pass elevations, rock system chronology, ISFR forest statistics).
* Advancing cards to Box 5 guarantees long-term retention.

### 8. 📓 Mistakes Notebook ("My Error Book")
* Automatically records every incorrect attempt.
* Classify errors by root cause:
  * *Conceptual Misunderstanding*
  * *Factual Lapse*
  * *Misread Question / Statement Trap*
  * *Careless Elimination*
* 1-click re-attempt and resolution workflow.

### 9. 📑 Official PYQs & Syllabus Mapping
* Official UPSC CSE Prelims papers (2015–2026) and State PSC exam repositories.
* Direct mapping to UPSC CSE Prelims GS-I and Mains GS-I/GS-III syllabus micro-topics.

### 10. 💾 100% Offline-First & JSON Backup
* Zero backend server required; runs entirely in the browser.
* 1-click JSON export and import for transferring progress, bookmarks, notes, and error logs across devices.

## 🚀 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/raghavendra-exp/geography-of-india.git
cd geography-of-india

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Create production build
npm run build

# 5. Preview production build locally
npm run preview
```

## 🌐 GitHub Pages Deployment

The repository is configured for automated zero-configuration deployment via GitHub Actions:
1. Go to your repository settings on GitHub: **Settings $\rightarrow$ Pages**.
2. Under **Build and deployment $\rightarrow$ Source**, select **GitHub Actions**.
3. Push changes to the `main` branch:
   ```bash
   git add .
   git commit -m "feat: complete Bharat Atlas Master v2.0"
   git push origin main
   ```
4. GitHub Actions will automatically compile the project and publish it to `https://raghavendra-exp.github.io/geography-of-india/`.
